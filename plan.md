# Полная модернизация Calories

## Цель
Развить текущий дневник питания в мобильное приложение в духе современных трекеров питания: дневной экран, цели, статистика, рецепты, партии продуктов, сканирование и облачное хранение без потери существующих данных.

## Сохраняемые данные
- продукты и их категории;
- партии продуктов и рассчитанное КБЖУ;
- записи дневника;
- блюда и ингредиенты;
- профили, цели и вода;
- синхронизация через Cloudflare D1.

## Реализация
1. Улучшить дневной экран: баланс калорий, макросы, прогресс, вода, приёмы пищи и быстрые действия.
2. Добавить статистику по дням/неделям: калории, БЖУ, вода, средние значения и прогресс.
3. Добавить вес профиля и историю веса без разрушения старого формата профилей.
4. Развить партии: выбор активной партии, дата и КБЖУ партии.
5. Улучшить рецепты: категории блюд, порции и добавление в дневник.
6. Сохранить существующие сканирование штрихкода, OCR этикетки, категории и облачную синхронизацию.
7. Добавить адаптивную мобильную навигацию и единый стиль.

## Ограничения
- не удалять старые поля и записи;
- новые поля добавлять с безопасными значениями по умолчанию;
- не хранить новые данные только в браузере;
- проверять JavaScript перед публикацией;
- публиковать только после успешной проверки.
